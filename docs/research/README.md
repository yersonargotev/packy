# Research evidence

The `evidence/` directory stores durable, dated investigation evidence. This
material is non-normative: remaining in the repository does not make research
evidence current architectural authority.

Current architecture is defined by the [accepted ADRs](../adr/), and current
domain language is defined by the [domain context](../../CONTEXT.md).

Temporary working material belongs outside the durable documentation set.
`.scratch/` remains local working material and must not retain committed files.
